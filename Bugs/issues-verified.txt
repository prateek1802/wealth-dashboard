   FIX: add an edit (pencil) button per row in transactions-view.tsx that opens
   TransactionDialog with editingTransaction={row} and asset={row.asset}.

6. Resizing window isn't responsive.
   STATUS: CONFIRMED, diagnosed earlier this session with screenshot (this is known
   issue #11 in PROJECT-STATUS.md). Root cause: table wrappers use `overflow-x-auto`
   but the <table> itself has no min-w-[...], so cells shrink/text wraps instead of the
   wrapper's horizontal scroll engaging. Affects transactions-view.tsx, portfolio-view.tsx,
   and growth-projection.tsx (analytics). Fix already specified in PROJECT-STATUS.md.
