WEALTH DASHBOARD — FEATURE IDEAS FROM LEADING WEALTH APPS
Researched: Empower (Personal Capital), Kubera, Monarch Money, Copilot Money, Quicken
Simplifi, and India-specific apps (INDmoney, Kuvera, Agni Folio) — Aug 2026.
Each idea below is mapped to what it would actually take in THIS app's stack
(Next.js + Supabase, single-user, mostly manual entry + some live price refresh).

====================================================================
🟢 REALISTIC — fits the current architecture, no new infra needed
====================================================================

1. Asset allocation drift / rebalancing alerts (Kuvera, Empower)
   Kuvera flags underperforming holdings against stated targets; Empower shows
   allocation vs. a target model. You already compute allocation % per holding and
   per asset-class group (ASSET_TYPE_GROUP). Add: a user-set target allocation per
   class (e.g. "70% Equity / 20% Debt / 10% Cash"), compare against actual, and
   surface a "you're 8% overweight Equity" banner on the dashboard.

2. Portfolio benchmarking against an index (Kubera: vs. S&P 500/Bitcoin; most apps: vs. Nifty)
   Kubera reports IRR per asset and benchmarks it against a chosen ticker/index. You
   already compute XIRR per holding and portfolio-wide. Add: fetch Nifty 50 / Sensex
   historical values (same live-provider pattern already used for Yahoo/CoinGecko) and
   show "Your portfolio: +14.2% XIRR vs. Nifty 50: +11.8%" alongside existing XIRR cards.

3. Recurring/subscription-style SIP reminder & tracking (most budgeting apps track
   recurring bills; adapted here for SIPs)
   You already have Maturity/reminder bell for FD/PPF/NPS/goals. Extend the same
   mechanism: let a mutual fund holding be flagged as "active SIP" with a day-of-month,
   and the bell reminds if that month's SIP transaction hasn't been logged yet by, say,
   the 5th of the month — catches missed/forgotten manual SIP entries, which matters a
   lot in a manual-entry app like this one.

4. "What changed" summary / weekly recap (Monarch's Weekly Recap, AI-powered Insights)
   Monarch auto-summarizes net worth/cash flow changes in plain language. A
   non-AI version fits easily here: a simple rules-based summary card — "Net worth up
   ₹42,000 this week, driven by SBI Contra Fund (+₹18,000) and NIFTYIETF (+₹9,000)" —
   computed straight from existing snapshot + holdings data, no LLM needed. Could later
   be upgraded to a real AI summary via the Anthropic API if desired.

5. Tax-loss / tax-gain harvesting flags (Kuvera's standout feature)
   Kuvera automatically flags underperforming direct-plan holdings for tax-loss
   harvesting. You already track cost basis and unrealized P&L per lot (FIFO). Add: a
   view that surfaces holdings with unrealized losses eligible to offset short/long-term
   gains elsewhere in the portfolio, with the relevant Indian STCG/LTCG holding-period
   rules (1 year for equity) already computable from existing lot dates.

6. Family / household multi-portfolio view (Kuvera, Kubera's sharing/collaboration)
   Kuvera supports family account management under one dashboard; Kubera has granular
   sharing. Given Supabase RLS is already per-user_id, this is a schema-level feature:
   add a "household" or "linked accounts" concept so someone can view (read-only)
   a spouse/parent's portfolio for a combined net-worth number — without merging the
   actual account data.

7. Physical/alternative asset tracking — gold, property, vehicles (Kubera's breadth;
   very relevant in India specifically — physical gold is a huge asset class here)
   Kubera tracks real estate, vehicles, precious metals, collectibles as manually-entered
   line items alongside synced accounts. Your schema already supports an "other" asset
   type loosely — this would formalize it: dedicated asset types for Physical Gold
   (with weight + purity), Real Estate (with a manual value + optional appreciation
   assumption), similar to how FD/PPF/NPS already get their own dedicated schema/UI
   rather than being crammed into the generic securities table.

8. Insurance & document vault (Safebox's differentiator vs. INDmoney/Kuvera —
   explicitly built for exactly the gap those "investor-first" apps have)
   A simple new feature area: policy name, type, premium due date, sum assured, renewal
   reminder (reuses the existing maturity/reminder bell pattern) — doesn't require
   actual document storage/encryption to start, just tracking dates and amounts.

9. Cash flow forecast (Quicken Simplifi's "Spending Plan" — forward-looking, not
   backward-looking)
   You already have XIRR-based growth projections. A simpler, more immediately useful
   version: project next month's contributions based on the "active SIP" data from #3,
   forecast known FD/PPF maturities in the next N months from existing maturity data —
   giving a "here's what's coming due/contributing in the next 90 days" view, purely
   computed from data you already store.

====================================================================
🟡 REALISTIC BUT NEEDS NEW INFRASTRUCTURE (cron, external APIs, or storage)
====================================================================

10. Automated bank/broker account sync via Account Aggregator framework (INDmoney,
    Kuvera, all major India apps use this — RBI's AA framework, e.g. via Setu/Finvu)
    This is the single biggest capability gap vs. every competitor researched — all of
    them auto-sync transactions instead of manual entry. It's also the biggest lift:
    needs AA-licensed aggregator integration (Setu, Finvu, OneMoney, etc.), consent flow,
    webhook handling. Large, dedicated project — not a patch. Worth flagging as the
    highest-value, highest-effort item on this whole list.

11. IRR/XIRR benchmarking against live index data (extends #2) needs a reliable Nifty/
    Sensex historical data source — same live-provider pattern as Yahoo/CoinGecko, but
    a new source needs identifying/testing (NSE doesn't have a simple free API; may
    need a Yahoo Finance ticker like ^NSEI).

12. Push/email notifications for maturity reminders, SIP reminders, target price hits
    (already deliberately deferred per PROJECT-STATUS.md — "no infra for it yet, in-app
    bell only"). Needs an email provider (Resend/SendGrid) or web push setup. The
    reminder DATA already exists (maturity bell, and #3/#9 above would add more) — this
    is purely a delivery-channel gap, not a data gap.

13. Scenario / "Fast Forward" planner (Kubera's unique feature — project net worth N
    years out under different assumptions: extra SIP, one-time withdrawal, market
    correction)
    You already have growth-projection.tsx doing XIRR-based projections. Extending it
    to an interactive "what if I invest ₹5,000 more/month" or "what if the market drops
    20% tomorrow" slider is mostly frontend work on top of existing calculation
    functions — moderate effort, no new infra.

====================================================================
🔵 WORTH KNOWING ABOUT, BUT LOW FIT FOR THIS APP'S PURPOSE
====================================================================

14. Full budgeting / category-level expense tracking (Monarch, Copilot, YNAB, Simplifi's
    core focus)
    All of the global leaders researched are budgeting-first apps with investment
    tracking bolted on — the opposite of this app, which is investment/net-worth-first
    by design. Bank Accounts already exist for cash tracking, but building out granular
    category-level expense budgeting would be a significant scope change, not a small
    addition. Flagging so it's a deliberate decision, not an oversight, if it's ever
    considered — same treatment PROJECT-STATUS.md already gives multi-currency and
    push notifications as "deliberately deferred."

15. Crypto wallet / DeFi / NFT tracking (Kubera's specialty)
    Asset type "crypto" already exists with CoinGecko live pricing for manually-entered
    holdings. Kubera's version — auto-detecting wallet balances from on-chain addresses,
    DeFi protocol positions, NFT floor prices — is a much deeper integration (wallet
    address scanning, multiple chains). Low priority unless crypto is a meaningful part
    of the actual portfolio being tracked.

16. Estate planning / legacy handoff / beneficiary notification (Kubera's "inactivity
    monitoring" + trusted-contact handoff; Agni Folio's similar nominee system for NRIs)
    Genuinely novel differentiator among competitors, but needs recurring "are you still
    there?" check-ins (cron-dependent) and a secure handoff mechanism — meaningful new
    infrastructure for a feature that's more about peace-of-mind than daily usefulness.
    Worth keeping in mind for later, not a near-term priority.

====================================================================
SUMMARY — best next moves if this list gets acted on
====================================================================
Highest value-to-effort, no new infra: #1 (rebalancing alerts), #3 (SIP reminders),
#5 (tax-loss harvesting flags — very India-relevant), #7 (gold/property as first-class
assets — very India-relevant given how much household wealth sits in physical gold here).

Sets up the future: #13 (scenario planner) builds cleanly on what growth-projection.tsx
already does.

Biggest single differentiator, but a real project of its own: #10 (Account Aggregator
auto-sync) — this is the one feature that separates every "big" competitor (INDmoney,
Kuvera, Empower) from a manual-entry tool. Worth a dedicated planning session on its own
rather than folding into a regular patch cycle.
